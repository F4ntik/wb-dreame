# Версия ядра Dreamehome

Источник — Tasshack/dreame-vacuum, версия интеграции v2.0.3, коммит `fec086caf064f2681e8bcc7be20a0d0ef54f444d`. Лицензия MIT и авторство сохранены в `src/vendor/LICENSE` и в каталоге документации пакета. Исходный device.py сверили по SHA-256 `40f9895f59ac7127cb395bb46b9302705b092faf642fccb189355f2a88793edc`.

[Исходный каталог на GitHub](https://github.com/Tasshack/dreame-vacuum/tree/fec086caf064f2681e8bcc7be20a0d0ef54f444d/custom_components/dreame_vacuum/dreame)

## Что адаптировано

- В map.py сохранены менеджер карт, редактор и декодер, включая NumPy-сетку, сегменты и применение кадров. Ветви рендера, зависимость от Pillow, JS-оптимизатор MiniRacer и обработка графики для карты истории удалены.
- В device.py удалены вспомогательные методы для отрисовки и статических картинок. clean_segment возвращает полученный ответ start_custom после штатной проверки его кода.
- Из protocol.py исключены Xiaomi Mi Home и локальный транспорт miIO. У облачного транспорта сохранились проверка сертификатов и подписей upstream, обработка OAuth и push. Для выравнивания блока и AES в заголовке региона используется библиотека cryptography, которую уже требует сам транспорт. Новые зависимости от Home Assistant, PyCryptodome и python-miio отсутствуют.
- Драйвер ограничивает вызовы RPC через `guard`. При обычной работе разрешены чтение свойств и служебные запросы карты. Веб-предпросмотр проверяет задание чтением. Отправка команды требует включённого разрешения и явного подтверждения. Драйвер записывает попытку до отправки и сохраняет неопределённый результат при тайм-ауте.
- const.py, types.py и exceptions.py сохранены с нормализацией окончаний строк. Встроенный архив таблицы возможностей в const.py является частью исходного кода upstream.
- Служба подавляет журналы vendor, где upstream может печатать ответы облака. Состояние «на связи» формируется по новому ответу get_properties. Заряд 0 сохраняется, пропущенное поле помечается ошибкой чтения.
- При чтении списка сохранённых карт и полных кадров учитываются изменения комнат и геометрии под прежним ID. Для заполненной сохранённой карты сравниваются сетка, размеры, названия и видимость комнат. Это позволяет принять разделение или объединение даже тогда, когда обычное сравнение MapData считает два ответа одинаковыми. Кадр v3 без вложенного полного плана также обновляет состав комнат сохранённой карты. Сетка плана поступает с полным снимком. Номер карты и номер кадра остаются разными полями протокола.

- Для команд используется контрольная сумма свежего списка MAP_LIST и соответствующего сохранённого плана. На L40s Pro Ultra проверено совпадение MD5 исходных байтов списка. Драйвер не подтверждает отдельный файл плана по контрольной сумме одного только списка.
- История использует штатные записи `CleaningHistory` и `get_history_map`. Собственный SVG-рендерер строит изображение из декодированной архивной сетки и сохраняет разрывы маршрута. Слой покрытия показывает обработанные и загрязнённые клетки при наличии маски decmap. Если маски нет, оценочная полоса шириной 250 мм строится по подтверждённым проходам влажной уборки и обрезается по клеткам пола. Фотографии препятствий читает штатный `get_obstacle_image` после выбора владельцем. Приватные ссылки и ключи остаются на контроллере.
- Во время уборки открытая панель запрашивает свежий кадр через существующий таймер Dreamehome. Панель опирается на состояние, полученное прямым чтением робота. Менеджер объединяет запросы вкладок и при устаревшем кадре может запросить текущий кадр раньше обычного повтора со старой отметкой времени. Ответ без кадра не запускает отдельную серию повторов.

- Сценарии Dreamehome читаются из свойства `SHORTCUTS` и запросов `GET_COMMANDS` и `GET_COMMAND_BY_ID`. При подтверждении драйвер повторно сверяет карту и определение сценария, затем отправляет штатный `START_CUSTOM` с его номером. Настройки сценария остаются в Dreamehome.
- Для доуборки драйвер сверяет свежую запись облачного журнала и её архивный кадр. В этом режиме ошибка чтения записи останавливает проверку. Для карты интерфейса декодер принимает номера комнат в диапазоне 1–63.
- Список завершённых уборок дополнительно сверяется с облаком каждые пять минут. Если запрос не удался, предыдущий список сохраняется и повторное чтение возможно через минуту.

## Перед включением команд

Сравнивай изменения upstream при переносе на новый коммит. При переносе на другую модель проверь регион, точный model string, перечень сегментов, соответствие геометрии карты, CleanGenius и состояние базы. Приватный API производителя может меняться независимо от выпуска Wiren Board. Для первой физической проверки на L40s Pro Ultra нужно согласие владельца. Подтверждение приёма команды и завершение фактической уборки — разные события.
