# Фото оборудования

В разделе «Ресурсы» для Dreame L40s Pro Ultra используются фотографии белой модели из [официальной карточки Dreame](https://ru.dreametech.com/product/robot-pylesos-l40s-pro-ultra/). Фото робота в галерее обозначено `03.jpg`, фото станции без робота — `05.jpg`.

Фото остаются у правообладателя. Репозиторий и пакет содержат ссылки на фотографии, а MIT-лицензия проекта относится к его собственным материалам. Разрешение на распространение копий фотографий не подтверждено.

При открытии раздела браузер может загрузить две фотографии с `api.ru.dreametech.com`. Запросы используют фиксированные адреса без данных робота и без заголовка `Referer`. Фотографии кэширует браузер по правилам сервера Dreame. При блокировке загрузки, работе без интернета или для другой модели показаны локальные пиктограммы. Показания робота и станции работают независимо от фотографий.
