Фотографии остаются у правообладателя. В репозиторий и Debian-пакет входят ссылки и собственные пиктограммы. Разрешение распространять файлы фотографий не подтверждено. MIT-лицензия проекта относится к его собственным материалам.

Браузер открывает фотографии при посещении «Ресурсов» для этой модели. Адреса фиксированы для всех экземпляров L40s Pro Ultra. Процент износа, режим, содержимое карты и адрес страницы в запросы не попадают. Используются два изображения с `api.ru.dreametech.com` и семь с `fr.dreametech.com`. Браузер кэширует их по правилам производителя. Пиктограммы видны с первого кадра, при отсутствии интернета, для другой модели и у деталей без подтверждённой фотографии. Показания поступают с контроллера независимо от загрузки фотографий.
